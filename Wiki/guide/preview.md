# 在线预览

双击文件，或右键「预览」，就在浏览器里打开预览器 —— 不需要下载，也不依赖任何在线服务。
预览器顶部是文件名与操作（下载、关闭），左右方向键可以切到同目录的上一个 / 下一个文件，
`Esc` 关闭。

## 图片

![图片预览](/images/viewer-image.jpg)

- 滚轮缩放、按住拖动平移，双击在「适应窗口」与「原始大小」之间切换。
- 方向键切换同目录图片，适合翻照片。
- 大图先出缩略图再加载原图，切换时不会白屏。

## 视频

用 ArtPlayer 播放，支持：

- **Range 请求**：拖动进度条即时跳转，不需要等整个文件下载完。
- **同名伴生文件自动挂载**：同目录下与视频同名的 `.vtt` / `.srt` 字幕、章节文件、进度缩略图
  会自动识别并挂上，不用手动选。
- 多字幕切换、章节跳转、进度条缩略图预览、氛围光（随画面取色）。
- 播放器按钮可以下载当前文件。

## 音频与歌词

音频用同一个播放器，另外支持**全屏歌词**：

- 读取文件内嵌的 ID3 元数据（标题、歌手、封面），有封面就显示封面。
- 歌词三类来源，按「自动」优先级取：文件内嵌歌词 → 网易云搜索 → 无歌词；
  也可以在歌词设置里手动搜索指定歌曲或直接粘贴文本。
- 在线歌词默认走网易云（`LYRICS_PROVIDER=netease`，免密钥）：**不配 Cookie 得到逐行歌词**，
  配了 `NETEASE_COOKIE`（网页版 Cookie 里的 `MUSIC_U=...`）就能拿到**逐字歌词（yrc）与翻译**，
  播放时按字推进高亮；Cookie 只存在服务端，前端拿不到。
- 播放器顶部会标出当前来源：内嵌歌词 / 自定义歌词 / 网易云 · 逐字 / 网易云 · 逐行 / 歌词库。
- 想继续用自建歌词库就设 `LYRICS_PROVIDER=lyriclib`，并填 `LYRICS_API_BASE` / `LYRICS_API_KEY`。

## PDF

浏览器内置 PDF 阅读器直接打开，支持翻页、缩放、搜索文字。移动端会退化成系统 PDF 查看器。

## 文本与 Markdown

纯文本按 UTF-8 / GBK 等常见编码依次探测，不会一上来就乱码；支持大文件分段渲染。

![Markdown 预览](/images/viewer-markdown.jpg)

Markdown 渲染成排版后的样子：标题、列表、表格、代码块（带高亮）、引用、任务列表都支持，
也可以切回源码看原文。

## Office 与 ODF 文档

| 格式 | 说明 |
| --- | --- |
| `.docx` / `.docm` | 用 docx-preview 渲染，保留大部分样式 |
| `.xlsx` / `.xls` | 表格按工作表分页渲染，可横向滚动 |
| `.pptx` | 逐页渲染成图片式版式，可翻页 |
| `.doc` / `.ppt` / `.rtf` | 旧格式与 RTF，尽量还原文字与基础排版 |
| `.odt` / `.ods` / `.odp` | ODF 本质是 zip + `content.xml`，纯前端解析还原 |

::: warning 只读预览
预览器不提供编辑与保存。改文档请下载后用本地 Office / WPS 打开。
:::

## 打不开的情况

- 文件超过预览上限时会提示「文件过大」，建议直接下载；上限与单文件上限一致（默认 4096 MB）。
- 浏览器不支持某编码（例如少见的压缩包内文本）时，只能下载后用本地软件打开。
- 压缩包、可执行文件等没有预览器，双击时直接走下载。
