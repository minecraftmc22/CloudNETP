# 分享链接

分享出来的链接是**独立公开页**，别人不需要注册也能打开，页面风格与主站一致。

## 创建分享

单个文件：右键 →「分享链接」。多个文件 / 文件夹：先多选，再点工具栏的「分享 N 项」，
会合并成**一条合集链接**。

![分享设置](/images/share-dialog.jpg)

三个可选项：

| 选项 | 说明 |
| --- | --- |
| 有效期 | 1 天 / 7 天 / 30 天 / 永久有效，默认 7 天 |
| 提取码 | 可选，1–8 位字母或数字；**服务端只存 scrypt 哈希**，事后任何人都查不到明文 |
| 下载次数上限 | 可选，1–999999；留空表示不限次数 |

点「创建链接」后弹窗显示结果，链接已自动复制到剪贴板：

![分享结果](/images/share-result.jpg)

## 管理已创建的分享

侧栏「我的分享」列出全部链接：

![我的分享](/images/shares.jpg)

每条显示分享的文件 / 合集、创建时间、有效期、已下载次数，可以复制链接、打开原文件，
或直接取消分享（取消后链接立即失效）。

列表按时间倒序分页，默认每页 10 条，可以在右下角切成 20 / 50 条（记在这台设备上）。

已经取消、过期、次数用完或文件被删的记录，右侧会变成两个按钮：

- **重新分享**：按原来的文件和时长生成一条新链接（原来带提取码的会换一个新的码，并复制到剪贴板）；
- **删除记录**：只删列表里的这条记录，网盘里的文件不受影响。

## 访客看到的页面

![公开分享页](/images/share.jpg)

- 单文件：显示文件名、大小、上传者昵称与头像（可在「设置 → 分享」里关掉，关掉后只显示昵称
  前两位且不露头像），可以直接预览或下载。
- 合集：一个列表，可以逐个预览 / 下载；**登录后**还能勾选若干项「保存到我的网盘」，
  转存到自己空间里。
- 有提取码的链接，先输码再显示内容；输错会提示重试。
- 双击文件就地预览，不用来回跳页。

## 链接失效了怎么办

| 提示 | 原因 |
| --- | --- |
| 分享不存在或已被取消 | 创建者删掉了这条分享 |
| 分享已过期 | 超过有效期，重新创建一条即可 |
| 下载次数已达上限 | 让创建者把上限调大或新建一条 |

::: tip 分享不会复制文件
分享只是给现有文件加一条访问规则，不占额外空间；原文件删除或移进回收站，链接随之失效。
:::
