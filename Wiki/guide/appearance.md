# 外观与个性化

界面按 WinUI 3 / Fluent Design 的风格做：Mica 亚克力卡片、圆角控件、分组设置卡。
下面这些都能在「设置」里改，改完立刻生效，并且跟着账号走。

![设置页](/images/settings.jpg)

## 外观

| 选项 | 说明 |
| --- | --- |
| 主题模式 | 亮色 / 暗色 / 跟随系统 |
| 主题色 | 预设色板、取色器任选，或「从背景图取主色」自动配一个 |
| 壁纸 | 4 套预设渐变（樱雾 / 夜樱 / 晨雾 / 林间），也可以上传自己的图；随时移除 |
| 界面语言 | 简体中文 / English，立即重绘 |

主题色会同步影响按钮、开关、进度条、选中态、图标强调色；暗色下卡片会自动换成半透明的
深色底，不会出现刺眼的白块。

## 模块不透明度

侧栏、标题栏、内容面板、卡片、弹窗五个表面可以**分别**调背景不透明度（`surface_opacity`）。
想要壁纸更明显就把面板调透，想要文字更清楚就调实，五个值互不影响。

「卡片」管的是内容区里那些小块：设置卡、关于页卡片、快传卡片（含列表行与提示卡）、
管理后台的统计卡、「我的文件」网格视图里的文件磁贴，以及「我的分享」底部分页条。
它和别的滑块略有不同 —— 卡的底色本来就各不相同，
所以这里的 100% 表示**保持默认观感**，往下拖是在这个基础上越来越透。

## 装饰

- **花瓣粒子**：登录页与主界面背景飘落的花瓣，可以整体关掉（低配设备上关掉更流畅）。
- **看板娘**：关掉后右下角的 CDP娘 不再出现，随时可以再打开。

## 手机端

![手机端](/images/mobile.jpg)

- 文件网格在窄屏下变三列，侧栏收进抽屉。
- 底部导航只留图标，52 px 高，避免挤压内容区。
- 设置页、管理后台、预览器都做了窄屏适配，不会出现横向滚动条。

## 分享页的外观

公开分享页复用同一套主题变量，所以访客看到的亮暗、主题色与你当前的设置一致；
分享页本身不提供切换按钮，除非访客自己也是登录用户。
