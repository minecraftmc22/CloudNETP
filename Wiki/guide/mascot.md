# 看板娘与 AI 对话

右下角常驻的 Live2D 看板娘叫 **CDP娘**。她不只是装饰：点开对话面板，她能真的翻你的目录、
搜文件、查容量，授权之后还能帮你新建文件夹、改文本、改名、复制、移动。

## 基本操作

- **拖动**：按住看板娘拖动位置，聊天气泡会跟着翻转、贴边时自动夹回窗口内。
- **缩放**：滚轮或拖动缩放（移动端用双指）。
- **悬停操作条**：鼠标移上去出现三个按钮 ——
  - **锁定**：鼠标穿透，看板娘不再挡点击，方便点她身后的文件；再点一次解锁。
  - **对话**：打开 / 收起右下角对话浮层。
  - **关闭**：本次会话隐藏看板娘。想再打开去「设置 → 装饰」把开关打开。

## 对话面板

![看板娘对话](/images/mascot-chat.jpg)

- 回复是 **SSE 流式**输出，字一个个出来，不用等整段。
- 模型的**思考过程**单独折叠在气泡上方，想看再展开。
- 工具调用显示成小胶囊，按调用 id 区分，能看到她在翻哪个目录、读了哪个文件。
- 底部输入框支持图片：点回形针选图，跟着问题一起发给模型（需要模型支持视觉）。
- `Enter` 发送，`Shift + Enter` 换行。
- 底栏右侧实时显示这一问的 **输入 / 输出 token**：流式过程中是按已收到的字估算（前面带 `≈`），
  回答结束后换成服务商给的准确用量；鼠标停上去能看到本次对话的累计。
  在「设置 → 看板娘 · 对话设置 → 显示 Token 消耗」可以关掉；走管理员提供的默认接口时
  不显示，也不向服务商索要用量（那部分账单不归你）。
- 数字左边有一个 **上下文占用圆环**：按服务商给的输入 token 数显示这一轮占了多少输入上限，
  接近上限会转成红色（该开新对话了）。上限取设置里的「输入上限」，没填时按 32K 估算；
  鼠标停上去能看到具体数字和百分比。

还没填接口时，面板顶部会有一行提示和「去设置」按钮。

## 历史对话

对话会**按账号自动保存**，不需要手动点保存：每轮问答、删除或编辑消息之后，界面把整段对话
同步一次。关掉页面、刷新、换台设备登录，再点开 CDP娘 会自动接着上次那段聊。

- 头部的 **时钟按钮**打开历史抽屉：列出保存过的对话（标题取第一句提问），显示条数与时间，
  点一条就能切回去接着问；右侧垃圾桶按两下确认可删除。
- 头部的 **加号**开一段新对话；旧的仍在抽屉里，随时可以翻回来。
- 每人最多保留 100 段，超了会删掉最久没动过的那段；一段对话正文最多 20 万字，
  图片沿用聊天时压好的尺寸，都存进自己的数据库，别人看不到。
- 「设置 → 看板娘 → 保存对话记录」可以关掉自动保存；关掉后不再新增，已有的记录仍然能查看、删除。

## 长期记忆

历史对话是「聊过什么」，长期记忆是「关于你这个人值得记住什么」。CDP娘 会在对话够长时
（离上次提炼超过 10 分钟）自动把偏好、习惯、明确说过的要求提炼成几条短句，去重后存进账号；
之后**每次对话**都会作为提示词的一部分带进去，跨对话生效。

历史抽屉的「长期记忆」页签里可以：

- 看全部条目，标着 **自动**（提炼出来的）或 **自定义**（自己写的）；
- 手写一条并「添加」，或删掉不准确的记忆；
- 点「从当前对话提炼记忆」立刻提炼一次，不用等自动触发。

「设置 → 看板娘 → 长期记忆」关掉后不再自动提炼，也不再注入提示词；已有条目仍可查看增删。
最多 40 条，自动提炼一次最多新增 5 条。

::: tip 记忆只是提示词，不是权限
长期记忆只影响 CDP娘 说话的方式与判断，不会给她任何文件读写权限；工具权限仍由
「数据操作权限」里的开关单独控制。
:::

## 问答工具（CDP娘 反过来问你）

缺少关键信息时（例如不知道要整理哪个目录、不确定是哪一个文件），CDP娘 可以调用问答工具
向你提问：

- 问题会显示成一条回答气泡，下面列出她**自动生成的候选回答**，点一下就作为你的回答发出；
- 最后一个固定是「自定义…」，点它把光标送回输入框，想写什么就写什么；
- 答完之后本轮的问题与回答都留在对话里，下一轮能接着上下文继续，也会一起进历史记录。

问答工具跟只读工具一样，只要「工具调用」开着就可用，不需要额外授权，也不会碰到文件。

## 配置接口

进「设置 → 看板娘 · 对话设置」：

![AI 对话设置](/images/ai-config.jpg)

| 配置项 | 说明 |
| --- | --- |
| 接口地址 | OpenAI 兼容（`https://.../v1`）或 Anthropic 的地址 |
| 密钥 | 落库前用 Fernet 加密，接口只回掩码，页面上看不到明文 |
| 模型 | 填完地址与密钥后可点探测，拉取可用模型列表下拉选 |
| 协议 | OpenAI 兼容 / Anthropic，跟随地址自动识别，也可手动指定 |
| 工具轮次上限 | 1–50，默认 8。到上限会收回工具让模型收尾，不会硬断 |
| 输入 / 输出上限 | 控制单次请求的 token 预算 |
| 显示 Token 消耗 | 默认开。管对话底栏那个实时数字，不影响实际请求 |
| 保存对话记录 | 默认开。关掉后不再新增历史对话，已有记录仍可查看 |
| 长期记忆 | 默认开。关掉后不再自动提炼、也不把记忆带进新对话 |
| 系统提示词 | 只显示管理员**自己写过**的内容；留空表示用内置默认 |

::: tip 内置提示词不下发到前端
内置人设有两版（中文 / 英文），跟着**界面语言**在服务端切换，任何接口都不会返回它的正文。
把输入框清空保存即可恢复默认；自己写过的内容属于用户内容，不会被翻译。
:::

## 工具与权限

只读工具默认可用：

| 工具 | 作用 |
| --- | --- |
| 列目录 | 按路径翻文件夹，带分页 |
| 搜索文件 | 按关键词搜整个账号 |
| 读文本 | 读文本类文件的前若干行 |
| 查容量 | 配额、已用、剩余 |
| 向用户提问 | 缺关键信息时反问一句，自动给出候选回答，最后一个是自定义入口 |

勾选「数据操作权限」后，才会额外下发写类工具：

| 开关 | 工具 |
| --- | --- |
| 允许写文件 | 新建文件夹、写 / 改文本文件 |
| 允许移动文件 | 重命名、复制、移动 |
| 快传取件码 | 生成取件码、用取件码取件（转存 / 给下载链接） |

未勾选时这些工具**根本不会出现在模型的工具列表里**，不是靠提示词拦。每次写操作都会在对话里
标成琥珀色，并在审计日志里记一条 `ai_tool`，事后可以从后台查。

### 快传取件码

打开「快传取件码」后，可以直接跟 CDP娘 说：

- 「帮我从我的文件里把账单.pdf 弄个取件码」——她会先搜到候选，**把完整路径念给你确认**
  （「是『文档/账单.pdf』这个吗？」），你确认后才真的生成，并把 6 位码、有效期一起告诉你；
- 「帮我取件，取件码是 ABC123」——她会列出这条码里的文件，再问你要转存还是下载；
- 「帮我取件，取件码是 ABC123，放到 图片/收件」——转存到那个目录，目录不存在会建出来；
- 「帮我取件，取件码是 ABC123，直接下载」——给出每个文件的下载链接。

每次工具调用都显示在回答**下方**的一条「使用工具 N」里，点一下才展开，能看到调用了什么、
结果是什么；写类工具（比如生成取件码）会标成琥珀色，并记进审计日志。

::: warning 聊天内容会发给你配置的服务商
AI 对话由你自己填的第三方接口完成，提问内容与工具返回的文件内容都会发过去。敏感文件别往里拖，
或者干脆用一个本地部署的兼容接口。历史对话与长期记忆保存在你自己的数据库里（不发给服务商，
但记忆内容会作为提示词参与之后的对话）；自动提炼记忆会额外调用一次同一个接口。
:::
