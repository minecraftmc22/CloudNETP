# WebDAV 挂载

挂上之后，网盘就是一个盘符：在资源管理器里拖文件等于上传，改完保存等于回写，
不用打开浏览器。

## 拿到地址与凭据

进「设置 → WebDAV」：

- **挂载地址**：形如 `http://192.168.1.24:8000/dav`，右侧有「复制」。
- **登录凭据**：用户名是你的用户名，密码**就是当前账号的登录密码**。
- 第一次用需要点凭据右侧的「待激活」标签，输入一次密码启用 WebDAV（不用重新登录）。

配了 `SITE_URL` 的话，这里显示的就是对外域名，例如 `https://pan.example.com/dav`。

## Windows

1. 资源管理器 → 右键「此电脑」→ **映射网络驱动器**
2. 文件夹填 `http://192.168.1.24:8000/dav`（也可以填 `\\192.168.1.24@8000\dav` 这种 UNC 写法）
3. 勾选「使用其他凭据连接」，用户名密码按上一节填
4. 完成后「此电脑」里多出一个盘符

::: tip 不会报 0x80070043
Windows 的 WebDAV 客户端默认不允许在明文 HTTP 上发送 Basic 密码，很多网盘因此要求你改注册表
`BasicAuthLevel=2`。本站的 `401` 响应**先给 Digest 再给 Basic**，Windows 看到 Digest 就会正常
带凭据重发，**不需要改注册表**。
:::

## macOS

Finder → 前往 → **连接服务器**（`⌘K`）→ 输入 `http://192.168.1.24:8000/dav` →
以「注册用户」登录，填用户名与登录密码。

## 手机与第三方客户端

RaiDrive、Documents（iOS）、ES 文件浏览器、Solid Explorer 等都可以新增一个 WebDAV 连接，
地址、账号、密码同上。RaiDrive 在 Windows 上还能把 WebDAV 映射成盘符并支持开机自动连接。

## 支持的操作

| 方法 | 用途 |
| --- | --- |
| `PROPFIND` | 列目录（资源管理器 / Finder 靠它显示文件） |
| `GET` / `HEAD` | 下载、取大小 |
| `PUT` | 上传 / 覆盖 |
| `MKCOL` | 新建文件夹 |
| `MOVE` / `COPY` | 移动、复制（支持整棵子树） |
| `DELETE` | 删除（进回收站） |
| `LOCK` / `UNLOCK` | Office 打开文档时的文件锁 |

写入同样受**配额**与**审计**约束：通过 WebDAV 传的文件会出现在「我的文件」里，
后台审计日志里记为 `dav_upload` 之类的动作。

## 排错

| 现象 | 排查 |
| --- | --- |
| 一直弹账号密码框 | 用户名是否是**用户名**而不是昵称；密码是否最近改过（改密码后要重新输入） |
| 能连上但列不出目录 | 地址要带 `/dav`，不要只填域名根路径 |
| 上传大文件失败 | 检查 `MAX_FILE_SIZE_MB`；反向代理（Nginx）还要放开 `client_max_body_size` |
| 公网访问很慢 | WebDAV 是逐请求往返，公网建议套 HTTPS 并确认上行带宽；大量小文件用浏览器上传更快 |

::: warning 公网使用请套 HTTPS
WebDAV 每次请求都带凭据，明文 HTTP 在公网上等于把密码交出去。用 Nginx / Caddy 做 TLS，
并把 `SITE_URL` 填成 `https://` 地址。
:::
