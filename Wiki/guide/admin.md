# 管理后台

管理员登录后侧栏出现「管理后台」。六个页签：概览、用户、举报审核、意见反馈、审计日志、系统设置。

![管理后台概览](/images/admin.jpg)

## 概览

- **运行状态**：版本、运行时长、数据库类型与当前模式（主库 / 降级 SQLite）。
- **存储**：总容量、已用、文件数与用户数，条状图看占用比例。
- **最近操作**：最新几条审计记录，点进去可到完整日志。
- **占用排行**：谁用得最多，方便找超额用户。

## 用户管理

![用户管理](/images/admin-users.jpg)

列表带搜索与分页，每行可以：

| 操作 | 说明 |
| --- | --- |
| 调整配额 | 单独设 GB 数，改完立即生效（已超额的部分不会被删） |
| 封禁 / 解封 | 封禁后该账号无法登录，已登录会话在下一次请求时失效 |
| 重置密码 | 生成新密码，用户下次登录用新密码；不会发邮件 |
| 设置角色 | 普通用户 / 管理员 |
| 级联删除 | 删账号连同其全部文件、分享、回收站记录；需要二次确认 |

## 举报审核

访客在分享页可以举报内容。这里列出举报条目，能直接看到被举报文件的预览与举报理由，
处理方式为「忽略」或「下架分享」。

## 意见反馈

用户在「关于」页提交的建议 / 问题汇总在这里，只有管理员可见。可以标记为已处理，
反馈内容、联系方式、提交人都会显示。

## 审计日志

![审计日志](/images/admin-logs.jpg)

覆盖 35 类动作：登录、注册、上传、下载、删除、还原、移动、复制、改名、分享创建 / 下载、
WebDAV 写入、后台设置变更、数据库切换、AI 工具写操作等。每条记录带操作者、动作、详情、
IP 与时间。

- 支持按动作、用户、时间范围筛选与分页。
- 审计动作名会按界面语言显示；没翻译的动作退回原始名称，不会出现 `审计动作:xxx` 这种前缀。
- 「系统设置 → 维护」里可以按天数清理旧日志，也可以手动清空。

## 系统设置

| 卡片 | 能改什么 |
| --- | --- |
| 站点 | 站点名称、公告、是否开放注册 |
| 找回密码兜底联系 | 管理员邮箱与 QQ，登录页「忘记密码」会显示 |
| 配额与上传 | 新用户默认配额、单文件上限、分片大小、回收站保留天数 |
| 快传取件码 | 最长有效期、单个文件下载次数上限、过期后文件保留天数，以及立即清理过期文件 |
| 快传取件码 | 最长有效期、单个文件下载次数上限、过期后文件保留天数，以及立即清理过期文件 |
| 版本更新 | 是否自动检查更新、手动更新按钮（git fast-forward + 重启） |
| 数据库 | 当前服务库、探活延迟、容灾副本状态，以及刷新配置 / 手动切换，见[数据库容灾](/guide/database.md) |
| 维护 | 清理审计日志、孤儿文件扫描、运行环境路径 |

::: tip 孤儿文件扫描
上传中断、数据库回滚都可能留下「磁盘上有 blob、但没有任何记录引用」的残骸。扫描会对比
磁盘与数据库，列出可回收的字节数，确认后清理。正常文件不会被误删。
:::

## 版本更新

- 关于页有「检查更新」，任何人都能点，只读地比对版本号，不会改代码。
- 后台「版本更新」卡片可以开自动检查提示，也可以直接点更新：只做 `git pull --ff-only`，
  然后按 `CLOUDNETP_RESTART_CMD`（或内置 `scripts/restart_helper.py`）重启。
- 前提：**git 检出、main 分支、工作区没有未提交改动**。私有仓库要在 `.env` 配只读
  `UPDATE_TOKEN`（fine-grained PAT，Contents: Read），否则匿名请求会 404。
- Docker / 压缩包部署不适用，请在宿主机重新拉取或覆盖文件。
