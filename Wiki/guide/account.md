# 注册与登录

## 注册

登录页右上角可以切换中英文，标题下方是「登录 / 注册」两个页签，切到「注册」：

![注册页](/images/register.jpg)

字段与规则：

| 字段 | 规则 |
| --- | --- |
| 用户名 | 4–32 个字符，中英文、数字都可以；登录时用它 |
| 邮箱 | 可选，用于以后找回密码；不填也能正常使用 |
| 密码 | 8–128 位，**必须同时包含数字与小写字母**，只能用可见 ASCII；大写与符号可选 |
| 确认密码 | 再输入一次 |
| 验证码 | 必填，输入右侧图片里的字符（不区分大小写） |
| 同意协议 | 必须勾选，否则提交按钮不会发请求 |

密码强度条会实时提示还差哪一项。注册成功后自动登录并跳转到「我的文件」。

::: tip 第一个账号是管理员
空库上注册的第一个账号自动获得管理员权限。之后注册的都是普通用户，配额取后台设置的
「新用户默认配额」（默认 10 GB）。
:::

## 登录

用户名 + 密码即可。连续失败 **2 次**后，表单会多出一个图形验证码，答错也算一次失败；
同一 IP 的失败次数过多会被限流一段时间。

忘记密码时点「忘记密码」，会显示管理员在后台填写的联系方式（邮箱 / QQ）。本站不发邮件，
需要管理员在[管理后台](/guide/admin.md)帮你重置。

## 用户协议与隐私政策

- 登录页与注册页的勾选行「已阅读并同意《用户协议》和《隐私政策》」里，两个书名号是链接，
  **新窗口打开**，不会冲掉你已经填好的内容。
- 两个页面也可以直接访问：`/terms`、`/privacy`，未登录状态可看。
- 正文按本站的实际实现写的：自托管意味着运营者（一般就是你自己或你的管理员）在技术上
  可以访问服务器上的文件与日志。条款正文只提供中文；英文界面下页面顶部会有一行提示
  「本页以中文版本为准」。
- 注册接口本身也校验同意字段 —— 绕过前端直接调 `/api/auth/register` 而没带 `agree`，
  会返回 `400`。

## 改资料与改密码

登录后进「设置 → 账号」：

- **头像**：点圆形头像选图，浏览器端先裁成正方形再上传，省流量也避免服务端收到巨图。
- **昵称 / 简介**：昵称会显示在侧栏与分享页。
- **修改密码**：需要输入当前密码；改完会让其他设备上的会话失效。
- **邮箱**：填了就能在忘记密码时作为联系依据之一。

## 界面语言

语言跟着账号走（存在 `user_settings.language`）。未登录时按「本机记住 → 浏览器语言 → 中文」
兜底，所以同一台机器下次打开还是上次的语言。

切换入口有两个：登录页右上角，以及「设置 → 外观 → 界面语言」。切换后整个界面立即重绘，
不需要刷新页面。
